# moa — AI Writing Assistant

## 로컬 실행

Node.js가 설치된 상태에서 `front` 폴더에서 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

```sh
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다. 종료하려면 터미널에서 Ctrl+C를 누르세요. 포트가 사용 중이면 `PORT=3001 npm run dev`로 실행할 수 있습니다.

## 현재 시제품

프론트엔드와 로컬 실행 파일은 모두 이 폴더에 있습니다. 회원가입에는 이메일, 8자 이상 비밀번호, 블로그 이름, 네이버 블로그 메인화면 링크가 필요합니다. 가입 후 로그인하면 글 편집기와 챗봇 화면이 열립니다. 빠른 확인을 위해 로그인 화면의 `데모 계정으로 바로 시작하기` 버튼도 사용할 수 있습니다. 오른쪽 위에서 주제 메모를 남기고, 새 글을 시작할 때 현재 글을 임시저장하거나 삭제하거나 취소할 수 있습니다. 임시저장본 목록에서 이전 글을 불러올 수 있습니다.

계정, 글, 메모, 임시저장본은 **현재 브라우저의 로컬 저장소에만** 저장됩니다. 로그인은 프론트엔드 시연용 mock 인증이며 실제 사용자 인증이나 다른 기기와의 동기화가 아닙니다. 챗봇도 준비된 예시 응답을 사용합니다. 실제 서비스에는 백엔드 인증, 데이터 저장소, LLM API를 연결해야 합니다.

`npm test`는 기존 글 생성 모델의 단위 테스트를 실행합니다.
